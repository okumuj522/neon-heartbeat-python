# Neon Heartbeat

A small animated ECG display made with Python and Tkinter. A taller ECG peak glides across a dark monitor in vivid, cycling rainbow colors. A soft double heartbeat sound loops at 48 beats per minute on Windows.

## Run it

Open PowerShell in this folder and run:

```powershell
python main.py
```

## Controls

- Press **Space** to pause or resume.
- Press **M** to mute or unmute the heartbeat sound.
- Press **Esc** to close the animation.

The project uses Python's standard library, so it does not need extra packages. The `heartbeat.wav` sound is generated automatically when the program starts.
